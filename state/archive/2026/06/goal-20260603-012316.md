Chạy DNA Engine trong **live mode** (giả lập giấy — paper) với nguồn candle **thật từ Binance REST API**, ghi journal vào PostgreSQL, và xác nhận end-to-end data flow hoạt động.

## 3. Flow end-to-end (đã được code hóa)

```
Binance REST API
     │
     ▼
BinanceCandleProvider.getCandles(tf, now, count)
     │  (oldest-first, exclude forming candle)
     ▼
buildTfSignal(tf, candles, bidVol, askVol, now)
     │  → computeTrendIndicators
     │  → computeMomentumIndicators
     │  → computeVolatilityIndicators
     │  → computeMicroIndicators
     ▼
TfSignal { tf, action, confidence, reason, indicatorSnap }
     │  stored in _lastTfSignals Map
     ▼
Khi ≥ minTfAgreement TFs ready:
     │
     ├─ detectRegime(indicatorsByTf, now) → RegimeSnapshot
     │
     ├─ computeConsensus({ tfSignals, regime, traceId, now })
     │   → weightedBullScore, weightedBearScore
     │   → gates: volatility | confidence | agreement | spread
     │   → ConsensusAction: enter_long | enter_short | hold
     │
     ├─ writeJournalEntry(...) → INSERT INTO dna_journal
     │
     ├─ emit({ type: 'consensus_computed', signal })
     │
     └─ executePaperConsensus(consensus)
         → emit({ type: 'paper_executed', entry })
```
