# /mekong-status

Inspect MEKONG wrapper CLI status: active goal, department SOP gates, MRR progress.

Run: `mekong-status` (no arguments needed)

Steps:
1. Check if there's an active goal state in state/ directory
2. List all department SOP gates and their status
3. Show current bottleneck departments
4. Display next command to execute for progress

Use when you need context about the overall project direction before coding.
