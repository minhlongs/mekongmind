# Mekong Content Hub — Design Guidelines

## Color Palette

- Primary: Blue (#2563eb) — actions, links, buttons
- Success: Green (#16a34a) — approved status
- Warning: Yellow (#eab308) — pending status
- Danger: Red (#dc2626) — rejected status
- Neutral: Gray scale (#f9fafb → #111827) — backgrounds, text

## Typography

- Font: system-ui, -apple-system, sans-serif
- Headings: font-bold, tight tracking
- Body: regular weight, 16px base, 1.6 line-height

## Spacing

- Base unit: 4px (0.25rem)
- Component padding: 16px (p-4)
- Section spacing: 32px (py-8) or 40px (py-10)

## Components

- Cards: white bg, rounded-lg, shadow-sm
- Buttons: rounded-md, 8px vertical padding
- Forms: border rounded-md, focus ring blue-500
- Badges: rounded-full, px-2 py-1, text-xs

## Layout

- Max content width: 5xl (1024px) for forms, 7xl for dashboards
- Responsive: md breakpoint (768px) for grid shifts
