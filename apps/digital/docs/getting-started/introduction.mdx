MekongMind is an **AI Agent Orchestration Platform** that gives you 25+ production-ready MCP tools, multi-provider LLM routing, and usage-based billing — all in one CLI.

## Two Engines

| Component | Description |
|-----------|-------------|
| **mekong-cli** | Python MCP server — 25+ tools, LLM routing, plan store, billing |
| **mekong-ide** | TypeScript IDE client (OpenCode fork) — typed MCP client, clean lifecycle |

## Key Features

- **25+ MCP Tools** — memory, tasks, plans, agents, diagnostics, trading, monitoring
- **Multi-Provider LLM** — BYOK for OpenAI, Anthropic, Google, or any OpenAI-compatible endpoint
- **Usage-Based Billing** — via Polar.sh. Free tier: 1K credits/mo. Pro: $29/mo.
- **Plan Store** — goal decomposition, task tracking, JSON persistence
- **No Lock-In** — bring your own API keys, stdio/SSE transport, self-hostable

## Who Is It For?

- **SEA Startups** — ship AI features faster without ops overhead
- **Indie Developers** — production AI infrastructure without enterprise tax
- **AI Teams** — multi-provider routing, audit trails, usage analytics
