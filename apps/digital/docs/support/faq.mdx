## What is MekongMind?

MekongMind is an AI Agent Orchestration Platform. It gives you 25+ MCP tools, multi-provider LLM routing, and usage-based billing via Polar.sh — all in one CLI.

## Do I need to host my own LLM?

No. MekongMind is BYOK (Bring Your Own Key). Set your API keys for OpenAI, Anthropic, Google, or any OpenAI-compatible endpoint. You can also run local models via MLX on Apple Silicon.

## How does billing work?

Usage is metered in credits. 1 credit ≈ 1 MCP tool call. Free tier: 1K credits/month. Pro: $29/mo for 50K credits. Enterprise: $199/mo unlimited.

## Can I use MekongMind with existing tools?

Yes. The MCP server speaks stdio and SSE. Connect it to any MCP-compatible client — Claude Desktop, Cursor, VS Code with Continue.dev, or our own mekong-ide.

## What's included in the Free tier?

All 25 MCP tools, full multi-provider LLM support, and community support on GitHub. 1,000 credits/month. No credit card required.

## Is there vendor lock-in?

No. BYOK + stdio/SSE transport means you can switch providers or stop using MekongMind at any time. Your data stays in your control.
