## 2. Phạm vi (Scope)

### 2.1. Chọn nền tảng POS (1 trong 3)
- [ ] **KiotViet** (default cho retail/F&B đơn giản, tạp hóa, hộ KD)
- [ ] **Sapo** (cho shop có cần website + POS + mạng xã hội đa kênh)
- [ ] **Misa eShop** (cho DN cần kế toán tích hợp sâu)

### 2.2. Setup
- [ ] Tạo tài khoản POS, config thông tin DN
- [ ] Import danh mục sản phẩm (CSV từ Excel khách)
- [ ] Setup thuế VAT, đơn vị tính
- [ ] Setup nhân viên + phân quyền (chủ, ca trưởng, thu ngân)
- [ ] Setup máy in hóa đơn (kết nối Bluetooth/USB)
- [ ] Setup máy quét mã vạch (nếu có)
- [ ] Setup tài khoản ngân hàng + ví điện tử (MoMo, ZaloPay, VietQR)
- [ ] Tích hợp hóa đơn điện tử (theo NĐ 123/2020) — Viettel/MISA
- [ ] Setup chương trình khuyến mãi cơ bản (giảm giá %, combo)
- [ ] Setup quản lý kho cơ bản (tồn kho, nhập-xuất)

### 2.3. Đào tạo
- [ ] Buổi 1 (2h, on-site Cần Thơ hoặc Zoom): chủ + ca trưởng
- [ ] Buổi 2 (1h, sau 1 tuần vận hành): hỏi đáp + fix issue
- [ ] Tài liệu hướng dẫn PDF + video screen-recording

### 2.4. Out of scope
- Thiết kế menu/in tem nhãn (giới thiệu printing partner)
- Tích hợp với website TMĐT custom (lập SOW WEB phụ)
- Migrate dữ liệu từ POS cũ phức tạp (cần SOW phụ, tính giờ)
- Custom report ngoài chuẩn (cần SOW phụ)

## 3. Pricing

| Tier | Phí setup | Số sản phẩm import | Buổi đào tạo |
|---|---|---|---|
| Basic | 3tr | < 200 SKU | 1 buổi |
| Standard | 6tr | 200–1000 SKU | 2 buổi |
| Premium | 12–15tr | > 1000 SKU + multi-store | 3 buổi + on-site |

**Reseller subscription (khách trả trực tiếp đối tác hoặc qua chúng tôi):**
- KiotViet: 200k – 500k/tháng tùy gói
- Sapo: 250k – 800k/tháng
- Misa eShop: 300k – 1tr/tháng

**Reseller margin (chúng tôi nhận):** 20–35% revenue đầu tiên năm 1, decline sau đó.

**Payment terms (setup fee):**
- 50% deposit khi ký
- 50% sau khi go-live + đào tạo buổi 1

## 6. Cam kết & SLA

- Go-live đúng ngày cam kết hoặc hoàn lại 10% setup fee
- Response Zalo/phone trong giờ hành chính: < 1h
- Bug critical (POS không in hóa đơn, mất data): on-site trong 4h tại Cần Thơ + lân cận
- 30 ngày sau go-live: free hỗ trợ minor issues
