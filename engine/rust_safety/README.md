# mekong_safety — Rust FFI Safety Library

P0 safety-critical cdylib exposing drawdown monitoring + kill-switch to Go via cgo.

## Quick Start

```bash
# Build dylib and copy to internal/ffi/lib/
./rust_safety/build.sh

# Run Go FFI tests (requires dylib present)
go test ./internal/ffi/... -v -count=1

# Run Rust unit tests
cd rust_safety && cargo test
```

## Architecture

```
Go (internal/ffi/safety.go)
  └── cgo → libmekong_safety.dylib
       ├── src/lib.rs        — 6 FFI exports + catch_unwind wrappers
       ├── src/guard.rs      — Guard: HashMap<Symbol, EquityCurve> + KillSwitch
       ├── src/drawdown.rs   — EquityCurve: rolling peak, drawdown_pct()
       └── src/kill_switch.rs — AtomicU8 state + ~/.mekong/kill.lock persistence
```

## FFI Function Table

| Function | Signature | Description |
|---|---|---|
| `msf_init` | `() -> *mut Guard` | Allocate Guard, restore kill.lock |
| `msf_record_equity` | `(guard, symbol, i64) -> i32` | Record equity, auto-evaluate drawdown |
| `msf_check_drawdown` | `(guard, symbol, *f32, *i32) -> i32` | Get drawdown%, ok flag |
| `msf_trigger_kill` | `(guard, reason_code: i32) -> i32` | Force KILLED state |
| `msf_is_killed` | `(guard) -> i32` | 1=killed, 0=ok |
| `msf_get_state` | `(guard) -> u8` | Get current state (0=OK, 1=WARN, 2=KILLED) |
| `msf_reset` | `(guard) -> i32` | Reset state to OK, remove kill.lock |
| `msf_free` | `(guard)` | Deallocate Guard |

## Error Codes

| Code | Constant | Meaning |
|---|---|---|
| 0 | MSF_OK | Success |
| -1 | MSF_ERR_NULL_PTR | Null pointer argument |
| -2 | MSF_ERR_INIT | Init failure |
| -3 | MSF_ERR_INVALID_STR | Non-UTF-8 symbol |
| -4 | MSF_ERR_INTERNAL | Mutex poisoned / IO error |
| -99 | MSF_ERR_PANIC | Rust panic caught at boundary |

## Kill-Switch States

| u8 | Constant | Description |
|---|---|---|
| 0 | STATE_OK | Trading allowed |
| 1 | STATE_WARN | Drawdown 7-10%, caution |
| 2 | STATE_KILLED | All trading halted |

Persistence: `~/.mekong/kill.lock` (1 byte, atomic write via tmp+rename).
Log: `~/.mekong/safety.log` (append-only, chmod 600).

## Drawdown Formula

```
drawdown_pct = (peak - current) / peak * 100
```

- `peak` = rolling maximum of all recorded equity values
- Threshold: 7% → WARN, 10% → KILL (hard cap, not user-configurable above 20%)
- Test vector: [1000, 1050, 1100, 950, 900] → 18.18% drawdown

## Phase 4b Completion — Orchestrator Retired (2026-04-14)

The old Rust Axum orchestrator has been removed. Replaced by:

1. Go CLI (`cmd/mekong/`, `internal/cli/`) — Cobra command tree with 7 subcommands
2. Smart Router (`internal/router/smart_router.go`) — Heuristic classifier (no LLM call)
3. Agent Pipeline (`internal/agents/pipeline.go`) — 4-step executor with kill-switch guards
4. Safety Management (`internal/cli/safety.go`, `internal/ffi/safety.go`) — `mekong safety status|reset`

This Rust safety library now provides FFI bindings only. Go handles all orchestration.
