## Content Templates

### Instagram Post Template
```
[Coffee image/video]

[Short engaging caption in Vietnamese]

Key details:
- Location: [address]
- Hours: 07:00 - 21:00
- Special: [today's special]

#AURACAFE #SaDecCoffee #ContainerCafe #MeKongDelta
```

### TikTok Script Template (30-60s)
```
Hook (3s): "POV: You found the best coffee in Sa Dec"
Body (20-40s): Show drink being made, ambiance, customer reaction
CTA (5s): "Come visit us at [location]"
```

### Facebook Post Template
```
[AURA CAFE] 

[Announcement/promo in friendly tone]

Details:
- Address: [full address]
- Phone: [phone]
- Hours: 07:00 - 21:00 daily

See you soon!
```
