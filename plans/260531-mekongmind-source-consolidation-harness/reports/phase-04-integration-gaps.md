## 7. `_BASE` Path Resolution in `openclaw_daemon_service.py`

**PARTIALLY CONCERNING** — Uses `MEKONG_HOME` env var with a fallback:

```python
_BASE = Path(os.getenv("MEKONG_HOME", Path(__file__).resolve().parent.parent.parent))
```

If `MEKONG_HOME` is unset, the fallback resolves 3 levels up from the file location:
- File: `/Users/macbook/mekongmind/cli/src/api/openclaw_daemon_service.py`
- 3 levels up: `/Users/macbook/mekongmind/cli/`

This is the correct project root, so the fallback works. However, `MEKONG_HOME` being unset could indicate the env var was never configured for this worker context, which may cause subtle issues if the daemon expects reports under `content/openclaw-reports/`.

**Recommended:** Verify `MEKONG_HOME` is set in the worker's `.env` file.
