# MekongMind Marketing Assets Spec

This document details the branding assets, copywriting templates, social media visuals, and interactive assets required for **MekongMind** marketing campaigns.

---

## 1. Brand Identity & Visual Assets

### Logo & Iconography
* **Primary Logo**: Clean, modern typography with a stylized "M" representing flowing water currents (symbolizing the Water Protocol (水)) merging with digital gears.
* **Palette**:
  * **Deep Obsidian**: `#0B0C10` (Dark background)
  * **Aqua Cyan**: `#66FCF1` (Active agents, flowing context)
  * **Digital Slate**: `#1F2833` (Containers, borders)
  * **Mekong Blue**: `#45A29E` (Bridges, tools, CLI output)
* **Favicon / App Icon**: A minimalist glowing cyan circle intersected by three parallel wave-lines.

## 4. Interactive Assets & Developer Documentation
To hook developer activation, we provide interactive documentation:
1. **Interactive CLI Demo**: A terminal emulator on the landing page allowing developers to type `mekong doctor check` and see simulated agent responses in real time.
2. **llms.txt (SEO Optimization)**: A structured index file located at `mekongmind.com/llms.txt` designed to be parsed by LLM code generation clients (like Antigravity IDE and Cursor), detailing all MCP tools and commands to maximize organic developer usage through AI assistant recommendations.
